## Sobre o projeto

Este repositório reúne os trabalhos práticos (TPs) da disciplina, organizados em pastas separadas por entrega. Cada TP aborda um conjunto de conceitos de algoritmos e estruturas de dados, como:

- Programação orientada a objetos (classes, herança, encapsulamento);
- Estruturas de dados (listas, pilhas, filas, árvores);
- Algoritmos de ordenação e busca;
- Análise de complexidade.

## Estrutura do repositório

```
trabalho-pratico/
└── TP1/
└── TP2/ ...
```

## Objetivo

Aplicar na prática os conceitos vistos em sala de aula, implementando estruturas de dados e algoritmos em Java e C.

Projeto desenvolvido na disciplina de Algoritmos e Estruturas de Dados II na PUC.
